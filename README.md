# muaziqubal20.vercel.app

Personal site of Muaz Iqubal: projects (AgentGuard, Job Radar, Sally, NeuraBar), writing
(*Living or Existing?*, served from `public/living-or-existing.pdf`) and résumé.

React + Vite, plain CSS with light and dark themes, set in IBM Plex. Deployed on Vercel from `main`.

```bash
npm install
npm run dev      # local preview
npm run build    # production build in dist/
```
